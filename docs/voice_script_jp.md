# 음성 대본 (서장 ~ 1장) — 일본어 번역

> 일본어 보이스 녹음용 대본. 한국어 원문 + 일본어 번역.
> 발화자 톤 가이드:
> - **하은**: 또래 캐주얼·솔직 (タメ口, 약간 발랄+경계)
> - **서연**: 안경 노트 분석가, 정중·논리적 (です・ます調, 차분)
> - **어둑시니**: ch1에는 직접 발화 없음 (ch3 이후 등장)
